# Инструкция по установке и настройке проекта на windows 

Это руководство поможет вам установить и настроить программное обеспечение для работы с проектом `api-ShortLog`.

---

## 1. Установка FFmpeg

1. **Скачайте FFmpeg**:
   - Перейдите на сайт [https://getffmpeg.org/](https://getffmpeg.org/).
   - Скачайте архив с FFmpeg для Windows.

2. **Распакуйте архив**:
   - Распакуйте скачанный архив в удобное место, например, в `C:\ffmpeg`.

3. **Добавьте FFmpeg в PATH**:
   - Откройте "Панель управления" → "Система и безопасность" → "Система" → "Дополнительные параметры системы".
   - В разделе "Дополнительно" нажмите "Переменные среды".
   - В разделе "Системные переменные" найдите переменную `Path` и нажмите "Изменить".
   - Добавьте путь к папке `bin` из распакованного архива FFmpeg (например, `C:\ffmpeg\bin`).
   - Нажмите "ОК" во всех окнах.

4. **Проверка установки FFmpeg**:
   - Откройте командную строку (`cmd`).
   - Введите команду:
     ```bash
     ffmpeg
     ```
   - Если FFmpeg установлен правильно, вы увидите информацию о версии и доступных командах.

---

## 2. Установка Node.js

1. **Скачайте Node.js**:
   - Перейдите на сайт [https://nodejs.org/en/download](https://nodejs.org/en/download).
   - Скачайте установщик для Windows (рекомендуется версия LTS).

2. **Установите Node.js**:
   - Запустите скачанный установщик и следуйте инструкциям на экране.
   - Убедитесь, что опция "Add to PATH" включена.

3. **Проверка установки Node.js**:
   - Откройте командную строку (`cmd`).
   - Введите команду:
     ```bash
     node -v
     ```
   - Если Node.js установлен правильно, вы увидите версию (например, `v18.12.1`).

4. **Проверка установки npm**:
   - В той же командной строке введите:
     ```bash
     npm
     ```
   - Если npm установлен правильно, вы увидите список доступных команд.

---

## 3. Установка глобальных библиотек

1. **Установите TypeScript**:
   - В командной строке выполните:
     ```bash
     npm i -g typescript
     ```

2. **Установите PM2**:
   - В командной строке выполните:
     ```bash
     npm i -g pm2
     ```

---

## 4. Скачивание и настройка репозитория

1. **Скачайте репозиторий**:
   - Откройте командную строку.
   - Перейдите в папку, где вы хотите разместить проект, например:
     ```bash
     cd C:\Projects
     ```
   - Выполните команду:
     ```bash
     git clone https://github.com/AlexBatya/api-ShortLog.git
     ```

2. **Переключитесь на ветку `version2.0`**:
   - Перейдите в папку проекта:
     ```bash
     cd api-ShortLog
     ```
   - Переключитесь на ветку:
     ```bash
     git checkout version2.0
     ```

3. **Проверка текущей ветки**:
   - Выполните команду:
     ```bash
     git branch
     ```
   - Убедитесь, что ветка `version2.0` выделена зелёным.

---

## 5. Установка зависимостей и сборка проекта

1. **Установите зависимости**:
   - В папке проекта выполните:
     ```bash
     npm ci
     ```

2. **Соберите проект**:
   - Выполните команду:
     ```bash
     npm run build
     ```

---

## 6. Запуск сервера

1. **Запустите сервер**:
   - Выполните команду:
     ```bash
     npm start
     ```
   - Если вы видите сообщение `Сервер запущен, батеньки...`, значит, сервер работает.

2. **Остановка сервера**:
   - Нажмите `Ctrl + C` в терминале, чтобы остановить сервер.

3. **Запуск сервера через PM2**:
   - Выполните команду:
     ```bash
     pm2 start server.js
     ```
   - Сервер будет работать в фоновом режиме.

---

## Итог

- FFmpeg установлен и добавлен в PATH.
- Node.js и npm установлены.
- Глобальные библиотеки (TypeScript и PM2) установлены.
- Репозиторий скачан, зависимости установлены, проект собран.
- Сервер запущен и готов к работе.

Теперь вы можете использовать сервер для обработки видео!
